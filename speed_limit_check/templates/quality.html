Precision sample (pilot)

How often do OSM, HERE, and our model match the real posted sign?

Samples at random (weighted by length) among segments where OSM, HERE, and our inferred speed limit don't all three agree, reads the actual speed-limit sign off Street View imagery (walking up to a few segments in each direction when the sampled one has none), and reports how often each source matches that ground truth - plus an inferred OVERALL precision for each source across the whole domain, assuming agreement means correct. Spends real Street View/Vision API cost - always saves its output to calc_tmp.precision_sample_results / calc_tmp.precision_sample_observations in BigQuery in addition to what's shown here.

A favors long segments (the share of road, so a highway counts for more than a connector); B treats every segment alike. 1 pools all states, so big or disagreement-heavy states dominate; 2 gives every state the same number of draws. The per-state options only differ from the pooled ones when State is US. The "Inferred overall" figures always use segment counts, whichever method drew the sample.

Analyzed signs

Report from signs already analyzed

Builds the same precision / recall / RMSE report purely from signs already recorded in calc_out.road_signs and calc_out.signs - no new Street View, Vision or Gemini calls, only a read-only BigQuery query (its cost is shown). Each segment's latest check is used. Origin picks which checks count: sampled = the segment a run set out to check; traversed = a neighbor only reached while walking along the road for a sign. These are measurements on the analyzed signs themselves, not a random sample, so no overall inferred figures are given.
