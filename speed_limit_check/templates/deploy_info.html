Who can reach it

Access

The public domain above is fronted by Identity-Aware Proxy (IAP), open to everyone at moove.ai - visiting it prompts a normal Google sign-in, and a personal (non-moove.ai) account is refused. The Cloud Run URL itself is the pre-IAP path and isn't how this is used day to day; who's actually let in is controlled by IAM's roles/iap.httpsResourceAccessor on the service.

Shipping a change

Deploying a new version

Run speed_limit_check/deploy.sh - it enables the required APIs, creates the cache bucket/secrets/service account if they don't already exist, deploys the current source to Cloud Run, and grants access. Safe to re-run; existing resources are detected and left alone. 

PROJECT_ID={{ project_id }} REGION={{ region }} BUCKET_NAME={{ bucket_name }} \
INVOKER_EMAIL=you@example.com MAPS_API_KEY=... \
SKIP_IAM_GRANTS=1 ./deploy.sh

SKIP_IAM_GRANTS=1 because Terraform owns this project's IAM grants already - see README.md's "Deploying to Cloud Run" section for the full variable reference and the manual step-by-step version.
